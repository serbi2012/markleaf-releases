# MarkLeaf 설치 파일

MarkLeaf 는 마크다운(.md) 문서를 읽기 좋은 화면 그대로 고치고, 고친 곳만 원래 파일에 저장하는 편집기입니다. 이 저장소에는 Windows 데스크톱판 설치 파일과 자동 업데이트 정보만 올라가며 소스 코드는 없습니다. [최신 릴리스](https://github.com/serbi2012/markleaf-releases/releases/latest)에서 `MarkLeaf-Setup-<버전>.exe` 를 받아 실행하면 되고(아직 코드 서명 전이라 처음 한 번은 "추가 정보 → 실행"), 설치한 뒤로는 앱이 스스로 업데이트합니다. 크롬 확장판은 [크롬 웹 스토어](https://chromewebstore.google.com/detail/markleaf/cnhfebgieoikabibmdeafajkccchadia)에 있습니다.
